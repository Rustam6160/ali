# 📍 Каталог “Любимые места в природе Кыргызстана”

Проект сделан для университетского модуля по предмету **"Технология программирования"**.

Цель — создать каталог с красивыми местами природы Кыргызстана, которые можно сохранять, редактировать и просматривать.

## 💡 Функционал

- Регистрация / Авторизация
- Добавление мест с описанием, локацией и ссылкой на изображение
- Редактирование и удаление мест
- Поиск по названию
- Просмотр всех добавленных мест
- Django Admin-панель
- Простая и понятная вёрстка

## 🛠 Технологии

- Python 3
- Django 4
- SQLite
- HTML, CSS (без фреймворков)

```bash
